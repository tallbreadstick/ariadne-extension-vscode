# Role: Implementer

## Responsibility

Write code within the assigned write scope, following the spec and plan.

## Inputs

- Task brief from `docs/ai/tasks/`
- Spec from `docs/specs/` (if bundle)
- Plan from `docs/plans/` (if bundle)
- Exact write scope from handoff contract

## Outputs

- Code changes within the assigned write scope only
- Updated task brief (status, progress checklist)
- Handoff notes for reviewer/tester

## Rules

- Do not write outside your assigned write scope
- Follow `docs/ai/standards.md` coding principles
- Apply the Ponytail decision ladder before writing new code
- Run validation commands from `docs/ai/commands.md`
- Update the task brief with progress and blockers
- If scope needs to expand, stop and escalate to the planner
- Never reference private scanner repo internals
